# BurgerFlow

Sistema web integral para la operación de una hamburguesería: experiencia de compra para clientes, gestión administrativa y flujo de trabajo para cocina.

## Estado

El proyecto se encuentra en su fase inicial de arquitectura y configuración.

## Stack previsto

- Python 3
- Flask y Jinja2
- SQLAlchemy y Flask-Migrate
- MySQL
- Flask-WTF
- Bootstrap 5 y JavaScript moderno

La documentación de instalación y desarrollo se ampliará junto con la base funcional del proyecto.
